# Tell Me About a Time You Helped Someone Grow

**Leadership Principles:** Hire and Develop the Best; Strive to be Earth’s Best Employer

**Use:** [Mentoring Interns and New Grads Through a Cloud-Native Learning Path](../core-stories/cloud-native-mentorship-learning-path.md)

## Draft answer

> I mentor interns and new graduates by sharing the cloud-native learning path that helped me build the platform skills I use at work. I wanted them to build practical ability through a progression of real systems instead of learning tools in isolation or being dropped directly into a production-grade Kubernetes environment.
>
> I created labs that build on each other: first, a static S3 website; then a dynamic EC2 website; then the same infrastructure recreated with CDK. From there, learners containerize the application and run it on ECS, build an EKS cluster with Argo CD and Karpenter, and finally create a build, development, test, and production delivery pipeline using Kargo.
>
> The goal is not simply to show people the platform. It is to give them a safe, repeatable path for understanding why each layer exists and how the pieces connect. Each stage has a visible result and prepares learners for the next one, helping them build confidence and independence as they work toward a full cloud-native delivery platform.

## What the interviewer is listening for

- You invest in other people’s development, even without formal management responsibility.
- You tailor support to what the person needs instead of simply giving answers.
- Your help creates lasting capability and independence.

## Skim notes

- Share learning path.
- Start with S3.
- Add EC2, CDK.
- Containerize with ECS.
- Build EKS platform.
- Deliver through Kargo.
- Build learner independence.

## Details to add before the interview

- How many interns or new grads have used the learning path?
- What did one learner build independently after starting the labs?
- How do you support a learner without taking over their debugging?
- What feedback changed the order, content, or guardrails of the labs?
- How do you make AWS cost, security, and permissions safe for learners?

## Likely follow-ups

- Why does the path start with S3 and EC2 rather than Kubernetes?
- How do you know when someone is ready for the next lab?
- How does the final Kargo pipeline connect to the platform you use at work?
